How to use the software

Select the menu generation mode

Select allergens to avoid for alternative menu

To select another allergen enter 1 and the choose the other one

If you prevoiusly selected the random menu option, it will be created automatically and saved in a file

Instead If the manual entry option has been selected, the list of dishes will be presented in succession by type for all 7 days of the week

In case the selected dish couldn’t be eaten by vegans, vegetarians, religious and intollerant people (the allergens were specified before in the b point), you will be asked to select an alternative dish for each of the previously elencated category.

In case of insufficient funds to continue with the purchase of the ingredients, you will be asked to insert other funds

After selecting all of the dishes, all of the menu will be written on a text file calle “menuSettimana.txt”

Error text

“errore: inserire solo numeri”

This text error indicates that in whatever choice the software gives you an opportunity to answer, you entered an alphabethic character instead of a number

Ex. In the choice of menu generation, if a letter is entered, the program will give this error and will ask the user for the choice until the entered input is suitable.

“errore: numero non valido inserire un numero compreso tra X e Y”

This error text indicates that the entered number is not between X and Y.

Ex. When choosing to generate the menu, if you enter a number greater than 2 or less than 1, the program will give you this error and will ask for the choice until you enter a correct number.

“errore: è stato selezionato un piatto non adatto”

This error indicates that when choosing substitute dishes, a dish is entered that is not suitable for vegans, vegetarians, religious people or allergy sufferers.
